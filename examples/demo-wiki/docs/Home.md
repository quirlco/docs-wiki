# Lantern docs

Lantern is a fictional note-taking app, and this folder is a small made-up wiki
about it. It exists to show what docs-wiki does with a real-looking set of
pages: links, backlinks, tags, decision records, and one page nobody links to.

## Start here

- What a [[notebook]] is, and how [[tagging]] cuts across notebooks.
- Why notes are plain files: [ADR-0001](decisions/0001-store-notes-as-plain-files.md).
- How devices stay in step: [ADR-0002](decisions/0002-sync-with-a-merge-log.md).
- The search screen: [search UI design](design/search-ui.md).
- When something goes wrong: [restoring from a backup](runbooks/restore-from-backup.md).

## How these docs are organised

| Folder | What lives there |
| --- | --- |
| `docs/decisions/` | One page per decision, numbered, each with a `Status:` line |
| `docs/concepts/` | The vocabulary the product is built from |
| `docs/design/` | How a screen or feature is meant to work |
| `docs/runbooks/` | Steps to follow when something needs fixing |
