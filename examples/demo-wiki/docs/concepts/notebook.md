# Notebook

A notebook is a folder of notes that share a name and a sync setting. Every
note belongs to exactly one notebook. Notebooks do not nest; use
[[tagging]] when a note belongs with others across notebooks.

A notebook's folder layout is decided in
[ADR-0001](../decisions/0001-store-notes-as-plain-files.md).
